# Plans

Written plans for work that has been decided — one kebab-case page per plan,
each listed here. Undecided ideas belong in `../todo/open.md` or the journal.

## Plans

* [MVP: the bar for the first usable version](mvp.md) — what must be true
  before v0.1 ships: every skill lands on a verified example, every
  `knowledge/` branch non-empty, the three README claims made checkable.
  The work queue in `../todo/open.md` follows this bar.
* [MLP: the bar for minimum lovable product](mlp.md) — what must be true
  before v0.2 is worth telling people about: three exemplar problems, ten+
  thinkers, five+ works, three+ schools, external validation, coverage
  ledger beating Wikipedia in one branch. Follows MVP; defines the next
  release target.
