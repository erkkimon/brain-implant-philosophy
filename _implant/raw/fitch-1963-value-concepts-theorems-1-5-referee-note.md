> "Received August 6, 1962."  (p. 135, first footnote block)

> "An earlier draft of this paper was presented as a retiring presidential address to the Association for Symbolic Logic; read before the Association at Atlantic City, New Jersey, December 27, 1961."  (p. 135, n. 1)

> "It is convenient to treat these possible states of affairs as propositions"  (p. 136)

Theorem 1 (p. 138) states that for any truth class closed under
conjunction elimination, the proposition that p is true but not a
member of the class is necessarily not a member of it; its formula
symbols are garbled in the OCR, so it is paraphrased, not quoted.

> "THEOREM 4. For each agent who is not omniscient, there is a true proposition which that agent cannot know."  (p. 138)

> "This theorem is essentially due to an anonymous referee of an earlier paper, in 1945, that I did not publish. This earlier paper contained some of the ideas of the present paper."  (p. 138, n. 5, attached to Theorem 4)

> "Proof. Suppose that p is true but not known by the agent. Then, since knowing is a truth class closed with respect to conjunction elimination, we conclude from Theorem 2 that there is some true proposition which cannot be known by the agent."  (p. 139, proof of Theorem 4)

> "THEOREM 5. If there is some true proposition which nobody knows (or has known or will know) to be true, then there is a true proposition which nobody can know to be true."  (p. 139)

> "Proof. Similar to proof of Theorem 4."  (p. 139)

The formula D6 (value) is garbled in the OCR and is not quoted. The
prose gloss that follows it is:

> "This means that a situation p is a value for an agent if (and only if) there is an actual situation q and situation r such that if the agent knows q then he will strive for the conjunction of p and r."  (p. 141)

Relied on for: Fitch's own wording of Theorem 5 (and Theorem 4, whose
proof it follows); the footnote crediting an anonymous 1945 referee;
the paper's origin as the 1961 retiring presidential address; the value
concept the theorems served.
Context: the paper analyses "striving for, doing, believing, knowing,
desiring, ability to do, obligation to do, and value for" (p. 135);
Theorems 1–2 concern any truth class closed under conjunction
elimination, Theorem 3 an all-powerful agent, Theorem 4 knowing, Theorem
6 proving. The word "paradox" does not occur in the extracted text of
the paper (checked by search, 2026-09-27).
