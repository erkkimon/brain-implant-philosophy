Relied on for: the ratchet origin as these authors report it, the two
versions, the ε = 0.005, M = 3 simulation setting, the convex-combination
framing, and their reply to Philips & Feldman's simple game.
Context: the simple game they examine is described as "game A: player loses
$2 if his capital C ( t ) is an odd number, and loses $1 if C ( t ) is an even
number; game B: the player gains $6 if C ( t ) is an odd number, and loses $7
is C ( t ) is an even number"; their simulation finds that game B alone then
wins ("However, game B is a winning game instead of a losing game as
specified in the proposed game 14 ."). They then classify eight schemes of
winning/losing games A and B in one probability space.
