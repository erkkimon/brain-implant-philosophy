# Positions

The answers — the *-isms*. A position page reports a thesis in its
proponents' own terms, the best case for it and the best case against it,
and who holds it. It never says which case wins.

**Symmetric steelmanning is the standard**: the case-for must be one a
proponent would accept as fair, and the case-against one an opponent would
accept as fair. Both are built from cited statements, never from the
implant's own reasoning ([Reporting, not endorsing](../../conventions/reporting-not-endorsing.md)).

A position is admitted when it has a named proponent in a citable source.
How many hold it is reported as data, never used as a reason to leave it out
([Selection is a stated rule](../../conventions/selection-is-a-stated-rule.md)).

## Page template

```
---
type: article
about: concept
title: <the position's usual name>
description: "<one sentence: the thesis, and which problem it answers>"
tags: [position, <field>]
timestamp: <ISO 8601>
---

# <title>

## Thesis
The claim, stated as its proponents state it — quoted where a canonical
statement exists, with its locator.

## Answers the problem
Link to the problem page(s).

## Canonical statements
The primary-text passages usually cited as defining the position, quoted to
the minimum, each with edition and canonical locator.

## Varieties
Named sub-positions and how they differ, attributed.

## The case for
The arguments proponents give, each linked to its argument page or cited.

## The case against
The objections opponents give, each linked or cited.

## Replies
Proponents' answers to the objections, cited.

## Who holds it
Thinkers (linked) and schools (linked), with the work where they state it.
Survey proportions where they exist, cited.

## Contrasts
The positions it is usually contrasted with, and the precise point of
divergence — which premise, which term.

## Vocabulary
Which senses of the contract terms this position uses.
```
