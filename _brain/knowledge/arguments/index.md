# Arguments

Named arguments and thought experiments, reconstructed as numbered premises
and a conclusion. Reconstruction is a logical operation on cited text and is
the one kind of analysis the implant does in its own voice; whether a premise
is *true* is never said here — only who accepts it and who disputes it, and
why, cited.

Validity of a deductive reconstruction is tool-checkable; the
[analyse-an-argument](../../skills/analyse-an-argument.md) skill does that.

```
# <title>

## Earliest primary source
Who first stated it, where (locator). If popular attribution and earliest
source differ, say so — the gap is a finding.

## Standard reconstruction
P1. …
P2. …
C.  …
Form: deductive | inductive | abductive | analogical; if deductive, the
schema (modus ponens, reductio, …). Whose reconstruction this is (cite).

## Supports
The position(s) it argues for, linked.

## Which premise is disputed, and by whom
For each premise: who rejects it, on what grounds, cited. This section is
the map of the disagreement.

## Objections
Named objections, each linked to its own argument page if it has one.

## Replies
Cited.

## Variants
Later reformulations, linked or cited.

## Vocabulary
Contract terms the argument turns on.
```
