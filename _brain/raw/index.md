# Raw

Undistilled source material: excerpts, survey rows, data — what knowledge
pages ground on and what future distillation reads. No frontmatter, no
links required, but orderly: kebab-case names that say what a file is,
listed here, pruned once distilled or proved worthless. Only excerpts,
never copies — see the convention
[Raw holds excerpts, not copies](../conventions/raw-holds-excerpts-not-copies.md).
brainpick excludes this folder from search results; grep it.
